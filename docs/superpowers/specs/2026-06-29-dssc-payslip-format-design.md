# Design: DSSC Payslip Body Format

**Date:** 2026-06-29  
**Approach:** B — Full data-driven two-column payslip body  
**Scope:** Body only (excludes institution header/logo banner)

---

## Overview

Rebuild the payslip generated by `PayslipDocument.cs` to match the DSSC payslip body layout:
- **Left column** — employee identity card + gross income + employer contributions
- **Right column** — itemized earnings/deductions table + totals + Net Pay + Certified By

Deductions displayed in parentheses (accounting format). Line items are stored as a flexible list in a new `PayrollLineItems` table, so any combination of deductions, additions, and employer contributions can be recorded per payroll run without hardcoding label names.

### New: PayrollLineItem Model

```csharp
public class PayrollLineItem
{
    public int Id { get; set; }
    public int PayrollId { get; set; }
    public string Label { get; set; }         // "GSIS", "BEO Deduction", "PERA", etc.
    public decimal Amount { get; set; }        // Always positive; sign determined by ItemType
    public PayrollLineItemType ItemType { get; set; }
    public int SortOrder { get; set; }
}

public enum PayrollLineItemType
{
    Earning = 0,               // shown as positive in right column
    Deduction = 1,             // shown in (parentheses) in right column
    EmployerContribution = 2   // shown in left column employer section only
}
```

Applied at app startup via versioned schema migration helper.

### Employees table
```sql
ALTER TABLE Employees ADD COLUMN AgencyId TEXT;
ALTER TABLE Employees ADD COLUMN SalaryGrade TEXT;
ALTER TABLE Employees ADD COLUMN Designation TEXT;
ALTER TABLE Employees ADD COLUMN FundSource TEXT;
ALTER TABLE Employees ADD COLUMN PayrollCycle TEXT DEFAULT 'Monthly';
ALTER TABLE Employees ADD COLUMN TinNumber TEXT;
ALTER TABLE Employees ADD COLUMN SssNumber TEXT;
ALTER TABLE Employees ADD COLUMN GsisNumber TEXT;
ALTER TABLE Employees ADD COLUMN PagIbigNumber TEXT;
ALTER TABLE Employees ADD COLUMN PhilHealthNumber TEXT;
```

### PayrollLineItems table (new)
```sql
CREATE TABLE IF NOT EXISTS PayrollLineItems (
    Id        INTEGER PRIMARY KEY AUTOINCREMENT,
    PayrollId INTEGER NOT NULL REFERENCES Payrolls(Id) ON DELETE CASCADE,
    Label     TEXT    NOT NULL,
    Amount    REAL    NOT NULL DEFAULT 0,
    ItemType  INTEGER NOT NULL DEFAULT 1,
    SortOrder INTEGER NOT NULL DEFAULT 0
);
```

### AppBranding table
```sql
ALTER TABLE AppBranding ADD COLUMN CertifyingOfficerName TEXT;
ALTER TABLE AppBranding ADD COLUMN CertifyingOfficerTitle TEXT;
```

## 4. UI Changes

### EmployeeModal.xaml
Add a new "Government IDs & Payroll Info" GroupBox below existing fields containing:
- Agency ID, Salary Grade, Designation, Fund Source
- Payroll Cycle (ComboBox: Monthly / Semi-Monthly / Daily)
- TIN, SSS, GSIS, Pag-Ibig, PhilHealth (TextBox each)

### PayrollModal.xaml
Replace the single `ManualDeductionAmountTextBox` / `ManualDeductionNoteTextBox` pair with:
- A `DataGrid` with columns: **Label** (editable TextBox), **Amount** (editable TextBox), **Type** (ComboBox: Earning / Deduction / Employer Contribution)
- Add Row button (appends blank row)
- Remove Row button (removes selected row)
- One "Salary" Earning row pre-populated from `GrossPay`

### Settings / AppBranding UI
Add two TextBox fields (Certifying Officer Name, Certifying Officer Title) to the existing admin settings area. If no settings window exists, create `SettingsWindow.xaml` — a simple dialog reachable from the main admin menu — containing only these two fields plus a Save button.

## 5. PayslipDocument Rebuild

### Signature change
```csharp
public static FlowDocument Build(
    Employee employee,
    Payroll payroll,
    List<PayrollLineItem> lineItems,
    string certOfficerName,
    string certOfficerTitle)
```

### Layout: 2-column outer Table (40% / 60% split)

**Left cell — Employee info card:**
```
[Employee Full Name — bold, 14pt]
──────────────────────────────────
Agency ID     | value
Salary Grade  | value
Date Hired    | value
Position      | value
Department    | value
Designation   | value
Payroll Cycle | value
Fund Source   | value
TIN           | value
SSS           | value
GSIS          | value
Pag-Ibig      | value
PhilHealth    | value
──────────────────────────────────
Gross Income  | ₱ amount
──────────────────────────────────
Employer Contribution
  [label]     | ₱ amount   (for each EmployerContribution line item)
```

**Right cell — Items table:**
```
ITEMS                         | (+) Amount  | (−) Amount
Salary (Earning)              | 73,303.00   |
[Deduction items]             |             | (x,xxx.xx)
[Earning additions]           | x,xxx.xx    |
────────────────────────────────────────────────────────
TOTAL                                       | xx,xxx.xx
NET PAY                                     | xx,xxx.xx

Certified By:
[CertifyingOfficerName]
[CertifyingOfficerTitle]
```

- Earnings: label + positive amount in left amount column
- Deductions: label + amount in (parentheses) in right amount column
- **TOTAL** row = sum of all Deduction line items (not net)
- **NET PAY** row = sum of all Earning line items − TOTAL deductions = `payroll.NetPay`
- Items sorted by `SortOrder`

### Print / SaveAsPdf
Both methods pass `lineItems`, `certOfficerName`, `certOfficerTitle` from their callers (PayrollModal + EmployeePayrollWindow).

---

## 6. Error Handling

- If `PayrollLineItems` table query fails, fall back to showing only Salary row + existing deduction fields (graceful degradation).
- If `CertifyingOfficerName` is blank, omit "Certified By" block from payslip.
- New Employee fields are all nullable — existing records without them show empty in the payslip info card.
